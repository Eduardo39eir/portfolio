# Portfólio — Eduardo Luna Floriano

Portfólio pessoal de desenvolvimento Front-End construído com **React**, **TypeScript**, **Vite**, **Tailwind CSS v4** e **Motion**.

**Visualização ao vivo (GitHub Pages):** https://eduardo39eir.github.io/portfolio/

## Principais recursos
- Layout minimalista com grade arquitetural responsiva e alternância de tema claro/escuro.
- Banner animado em pixel art com suporte silencioso a `prefers-reduced-motion`.
- Exibição de projetos com modal de detalhes acessível por teclado.
- Stack de tecnologias com filtros por categoria e barra de contexto.
- Calendário real de contribuições do GitHub (`@Eduardo39eir`).

## Executar localmente

```bash
npm install
npm run dev
```

## Build de produção

```bash
npm run build
npm run preview
```

## Personalização rápida
Todos os dados de perfil, links, projetos, stack e mídias ficam centralizados em `src/data/portfolioData.ts`.
